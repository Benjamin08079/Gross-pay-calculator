# Gross-pay-calculator
A beginner python project to calculate gross pay.
this python project calculates gross pay based on the user-input hours and rate per hour.
# Features:
-prompts the user to enter the number of hours worked and the hourly rate
-Calculates regular pay for up to 40 hours
-Applies 1.5x overtime rate for hours beyond 40
-Displays the total gross pay

# Sample intput
Enter Hours: 45
Enter Rate: 10.50

# Sample output
Pay: 498.75
